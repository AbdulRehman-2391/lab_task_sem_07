# Landmark Recognition Using SIFT

## Overview
This project implements a landmark recognition system using Python and OpenCV. It uses the SIFT algorithm to detect and match image features for identifying famous landmarks.

## Technologies Used
- Python
- OpenCV
- NumPy
- Pandas
- Matplotlib
- SIFT Algorithm

## Features
- Automatic landmark image collection
- SIFT feature detection and extraction
- Feature matching using Brute-Force Matcher
- Lowe's Ratio Test
- RANSAC-based verification
- Landmark recognition and localization
- Recognition accuracy evaluation

## How to Run
1. Install the required libraries:
   `pip install opencv-python numpy pandas matplotlib requests`
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Run all cells sequentially.
